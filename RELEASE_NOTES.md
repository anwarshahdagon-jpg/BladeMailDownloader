Free download manager for Windows, with a browser extension.

## Download
Download **BladeMail-Download-Manager-Setup-x.y.z.exe** below (under Assets) and run it. No administrator rights needed.

**Windows warning:** the installer isn't code-signed, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**. Your browser may also ask you to confirm keeping the file.

## Add the browser extension
When the installer finishes, BladeMail opens a short guide with one button per browser. In each browser: open the extensions page, turn on **Developer mode**, click **Load unpacked**, and pick the folder the guide shows. Chrome, Edge, Brave, Opera, Vivaldi and Firefox are supported. Firefox needs this again after each restart.

## Features
- Several connections per file for full speed, with pause and resume that survive restarts
- Takes over browser downloads, plus a "Download video" button and an audio-only ♪ button on videos
- Right-click "Download all links on this page" with type filters
- Scheduler, speed limiter, auto-retry, duplicate check, checksum check
- History and stats, dark and light themes, mini speed window, taskbar progress

It does not download DRM-protected video (Netflix, Spotify and similar).

The installer was built by GitHub Actions from the code in this repository.
