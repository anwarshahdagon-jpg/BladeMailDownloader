Add BladeMail to your browsers

Browsers only let you install extensions from outside their store yourself, so this takes one click per browser. For each browser below: click Open extensions page, turn on Developer mode, click Load unpacked and pick the folder that opens with Show folder (its path is also copied for you).

Updating from FluxGet? On each browser's extensions page, first click Remove on the old “FluxGet Connector” (its folder no longer exists), then load the new folder.

Firefox: on the page that opens click Load Temporary Add-on… and choose manifest.json in the Firefox folder. Firefox removes unsigned add-ons when it closes, so you will need to do this again after restarting Firefox (Firefox Developer Edition or ESR can keep it permanently with xpinstall.signatures.required set to false). Also open the add-on's settings and allow Access your data for all websites.
